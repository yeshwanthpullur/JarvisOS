# Web Research Pipeline

Phase 6 classifies browser and crawler actions before selecting a tool. Public HTTPS reading and extraction can proceed only when read-only network policy is enabled. Controlled browser opening, screenshots, clicks, downloads, and uploads require exact approval and a broker-capable adapter. Login, form submission, messaging, posting, purchases, remote deletion, and account changes remain blocked in the Phase 6 adapter.

Crawls are bounded to five pages, depth one, 60 seconds, two concurrent requests, one retry, content/download limits, and rate controls. Private/local targets are rejected. Crawl4AI is the planned primary and Firecrawl the backup; neither is auto-installed or automatically authorized. Existing read-only web handling is the safe fallback.

Research evidence must retain source URL/reference, title, publisher, retrieval time, excerpt, freshness, relevance, credibility, and conflict notes when available. No citation is fabricated. Browser and crawler metadata cannot automatically update Memory or Knowledge.
