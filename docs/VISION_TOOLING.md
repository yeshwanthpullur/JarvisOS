# Vision Tooling

Phase 6 normalizes local visual evidence before it reaches Vision Intelligence. Explicit image files are size/type checked, treated as untrusted evidence, referenced by display name, and not retained by this adapter. Ollama/LLaVA remains the primary verified analysis path; Florence-2, PaddleOCR, EasyOCR, and Tesseract are optional unconfigured adapters.

Camera enumeration and capture, background monitoring, identity recognition, sensitive-trait inference, cloud upload, and automatic memory or knowledge writes are disabled.
