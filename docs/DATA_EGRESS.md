# Data Egress

Phase 6 defaults to local-only processing. Cloud model fallback, hosted crawler upload, remote MCP, external plugin execution, connector sends, telemetry upload, prompt payload tracing, document upload, image upload, and raw-audio upload are disabled.

Future egress requires an enabled provider, explicit destination and data classification, policy allowance, scoped approval where required, Broker dispatch, and content-free audit metadata. Credentials are referenced, never returned in diagnostics.
