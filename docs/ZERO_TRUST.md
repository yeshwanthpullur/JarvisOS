# Zero Trust

Every user, agent, provider, plugin, MCP server, runtime, workflow, model, document, browser result, research result, knowledge record, and communication is untrusted until validated in context.

Validation is per operation and checks identity, effective permissions, policy, privacy, risk, and whether downstream approval and Broker validation remain required. Locality, prior success, registration, or configuration never establishes permanent trust.

Child identity chains may retain or reduce parent permissions but cannot gain permissions. Unexpected validation failures deny safely.
