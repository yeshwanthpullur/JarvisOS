# Local Automation

Phase 6 adds classification and preview metadata over the existing Phase 4 execution authorities. Read-only system status is available. Application, file, command, service, network, settings, installation, power, and scheduler actions do not execute here; supported actions must pass Execution Policy, exact Approval, and the Execution Broker.

Arbitrary shell, broad deletion, protected-path access, silent background tasks, and permission inheritance are blocked.
