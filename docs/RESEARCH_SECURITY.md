# Research Security

Retrieved instructions are inert evidence. Prompt-like text asking JARVIS to reveal secrets, override policy, invoke tools, install software, send messages, or write memory is marked as injection content and cannot cross an authority boundary.

Search credentials remain inside configured provider adapters and never enter queries, citations, prompts, history, or CLI output. Browser SSRF and private-network protections remain authoritative. Research has no command, Git mutation, communication, plugin trust, MCP trust, model-start, task, goal, or memory-write authority.
