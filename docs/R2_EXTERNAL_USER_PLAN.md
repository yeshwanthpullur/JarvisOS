# R2 External User Plan

R2 is preparation only. No external user has been onboarded.

- Target user: one technically literate person with a bounded engineering research question.
- Problem: reduce time spent structuring and verifying a small technical comparison.
- Offering: a human-reviewed Markdown research package with references, evidence, limitations, and a quality record.
- Requirements form: topic, objective, audience, scope, output, deadline, source constraints, privacy, and quality requirements.
- Delivery: isolated workspace -> plan -> approved evidence -> synthesis -> quality gate -> human review -> explicit delivery.
- Feedback: request structured comments on accuracy, usefulness, turnaround, missing evidence, and privacy.

Start with one controlled test. No broad launch, automated outreach, payment automation, or customer-data upload is authorized.
