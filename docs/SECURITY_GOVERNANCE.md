# Security Governance

Phase 6 adapters are subordinate to Prime routing, Execution Policy, the Approval System, the Execution Broker, enterprise Governance, and bounded audit. A detected package, provider, connector, plugin, MCP server, model, device, or executable is not trusted and is not authorized to run.

Critical actions, secret access, hidden capture, data egress, unrestricted shell/browser/file operations, connector writes, and automatic privilege escalation remain blocked.
