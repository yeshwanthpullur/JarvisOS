# Adapter Foundation

Prompt 57 adds bounded adapter manifests, explicit permission metadata, capability diagnostics, and plan-only integration checklists. The Adapter Agent can describe future MCP, plugin, API, and webhook integrations without executing them.

MCP runtime, external plugin installation, arbitrary tool loading, network connectors, webhooks, command execution, file writes, credentials, message sending, and background servers are disabled.

Commands: `adapter status`, `help`, `list`, `show`, `plan`, `safety`, `permissions`, `capabilities`, `show-job`, and `history`.
