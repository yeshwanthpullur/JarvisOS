# Munder Adapter

Munder is an optional workspace adapter. A callable Munder launcher was not detected at the implementation checkpoint; no UI application was launched or searched through private directories. Its contract allows metadata discovery and plan-only use inside an explicit directory under an allowed workspace root. Missing application registration, startup, or workspace support degrades cleanly, and direct JARVIS-to-worker adapters remain available.

The adapter does not launch Munder, discover projects outside the supplied root, use bypass flags, or grant repository-write permission. If Munder becomes available later, it must still use Approval, Broker, worktree, review, and bounded artifact rules.
