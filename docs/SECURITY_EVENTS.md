# Security Events

Bounded security events represent authentication, authorization, policy, credential, provider, plugin, MCP, browser, GitHub, workflow, and other governance outcomes. Events may be correlated only by explicit workflow, session, identity, provider, runtime, policy, or correlation references.

Incidents have detected, investigating, contained, resolved, closed, and manual-review states. Recommended actions such as pausing a workflow or requesting operator review are advisory and cannot trigger privileged recovery.
