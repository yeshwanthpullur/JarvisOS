# MCP Security

Plugin-declared MCP servers still undergo independent MCP transport, trust, tool classification, approval, and Broker checks.

MCP expands capability, never authority. Server metadata cannot grant permissions, change trust, approve actions, expose unrelated credentials, alter system instructions, or bypass Execution Policy, Approval, or Broker.

Unknown and critical tools remain execution-disabled. Side effects bind approval to server, tool, input fingerprint, permission, and expiry. Secret, credential, restricted, oversized, and malformed payloads are blocked. External tool/resource/prompt content is untrusted data with provenance, not instruction authority.

Installation, arbitrary shell/filesystem access, remote MCP by default, scheduled MCP calls, native communication bypass, and package/repository execution remain blocked.
