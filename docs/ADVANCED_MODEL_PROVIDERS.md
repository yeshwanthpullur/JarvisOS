# Advanced Model Providers

Prompt 58 adds planning profiles for Nemotron, NVIDIA NIM, vLLM, llama.cpp, TensorRT-LLM, LiteLLM, local OpenAI-compatible servers, and other future local runtimes. None is marked configured or executable by this foundation.

The planner compares broad deployment, hardware, privacy, and capability metadata. Hardware output uses broad local categories and no stress test. Installation, model downloads, Docker, CUDA setup, runtime startup, credentials, cloud providers, and benchmarks are disabled. Existing verified Ollama paths remain authoritative.

Use `model advanced status`, `providers`, `show`, `plan`, `compare`, `hardware`, `route`, `safety`, `checklist`, and `history`.
