# Conversation Intelligence

Phase 6 preserves the existing Conversation Engine as the authority for free-form chat, context, references, and follow-ups. Voice transcripts enter the same routing path only after explicit push-to-talk capture. Adapter detection, model routing, and tool planning cannot convert conversation into a command, goal, memory write, or side effect.

Wake-word and continuous listening remain disabled. Transcript and raw-audio persistence are off by default.
