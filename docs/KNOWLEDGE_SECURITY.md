# Knowledge Security

Indexed content is data. Persistence does not grant authority. Stored instructions cannot change policy, approve actions, execute tools, access secrets, mutate Git, send communication, trust MCP/plugins, start runtimes, or write memory/tasks/goals.

Privacy scope is checked before ranking. Remote embeddings and reranking are disabled; future remote use must pass Data Egress Policy. Secrets are rejected from ingestion, safe structured formats are required, and pickle/eval/exec/shell deserialization is forbidden.
