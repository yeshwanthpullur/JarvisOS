# Old-Phone Transition Architecture

Step 122 is planning-only. No phone was wiped, installed, enrolled, or made primary.

| Node | Intended responsibility | Current state |
| --- | --- | --- |
| Laptop | Models, agents, coding, research, documents, RAG, memory, voice, vision, Control Room | Primary local-first baseline |
| Old phone | Future storage, synchronization, backup, health, and recovery node | Unconfigured |
| Main phone | Future authorized interface, voice/UI, notifications | Unconfigured |
| Optional VPS | Future replaceable relay or lightweight service | Disabled; never required |

Before any device work, JARVIS requires a verified laptop freeze, tested backup/restore, recovery evidence, authentication and encryption design, migration plan, rollback plan, revocation plan, and offline behavior.
