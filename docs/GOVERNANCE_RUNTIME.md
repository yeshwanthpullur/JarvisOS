# Governance Runtime

The Governance Registry stores bounded identities, roles, policies, risk definitions, trust metadata, compliance results, audit categories, and retention classes. Runtime state is in memory and is never exposed through Vercel.

Governance integrates with Executive, Prime, Workflow, Orchestrator, Reliability, providers, models, plugins, MCP, research, knowledge, browser, GitHub, and communication through metadata references. It does not replace their authoritative controls.

The CLI provides bounded `security` diagnostics. No command changes permissions, approves requests, executes tools, or modifies policies.
