# Startup

1. Clone the repository and enter its directory.
2. Create or activate an isolated Python environment; install only the documented project dependencies.
3. Review `.env.example` if present. Never commit `.env` or credentials.
4. Start with `python main.py`.
5. Run `project status`, `status`, and `engineering status`.
6. Confirm local provider and privacy state before using optional capabilities.

The normal path is CLI-first. `--ui` is optional and experimental. Do not expose Ollama, MCP, browser, microphone, or connector services publicly.
