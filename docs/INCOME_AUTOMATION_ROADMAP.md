# Income Automation Roadmap

The sequence is: foundation, one useful deliverable, a small legitimate external test, first payment through an eligible account route, repeat delivery, positive contribution margin, and only then subscription independence. No milestone is advanced without dated evidence.

## Maturity

`L0 Manual` -> `L1 AI-assisted` -> `L2 Script-assisted` -> `L3 JARVIS-orchestrated` -> `L4 Multi-agent` -> `L5 Scheduled` -> `L6 Verified repeatable`.

Current services are `L0-L2 plan-only foundations`. Scheduling, publishing, unsolicited outreach, financial automation, and platform manipulation are out of scope.

## Operating loop

Customer problem -> scoped workflow -> deliverable -> quality check -> human approval -> feedback -> versioned skill -> bounded automation. Content creation follows research, script, asset plan, QA, and human review; it does not auto-publish.
