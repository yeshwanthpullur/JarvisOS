# Outbound Message Security

Outbound plans require explicit destinations, narrow provider permissions, data-egress classification, content redaction, attachment validation, rate limits, duplicate protection, and exact approval. Secret, credential, restricted, bulk, spam, scheduled, attachment, contact-scraping, and unapproved requests are blocked.

History stores bounded metadata only: no full bodies, tokens, contact lists, private attachments, authorization headers, cookies, or provider sessions.
