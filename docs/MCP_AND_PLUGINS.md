# MCP And Plugins

MCP servers and external plugins are represented only by disabled manifests and future permission plans. No server is installed or launched, no plugin code is loaded, and no credentials or network connection is used.

A future executable adapter requires sandboxing, explicit provenance, capability review, least-privilege permissions, a credentials vault, user approval, bounded output, cancellation, audit, and subsystem-specific tests. Until then, `adapter_agent` remains manifest-only.
