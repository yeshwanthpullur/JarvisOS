# MCP And Plugins

External plugins remain disabled manifests and future permission plans. MCP now has an official-SDK local stdio client and one configured Playwright server trusted only for discovery. Explicit discovery may launch the already cached local package in an isolated headless context, enumerate bounded metadata, and stop it cleanly. No discovered tool is trusted or executable, no package is installed, no plugin code is loaded, and no credential is imported.

A future executable adapter requires sandboxing, explicit provenance, capability review, least-privilege permissions, a credentials vault, user approval, bounded output, cancellation, audit, and subsystem-specific tests. Until then, `adapter_agent` remains manifest-only and MCP tool execution remains policy-disabled.
